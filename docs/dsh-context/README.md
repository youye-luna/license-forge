## 迁移的边界（重要）

Trae 的 AI 记忆库位于 `~/.trae-cn/memory/projects/<slug>/`，其中 slug 形如
`-e----<路径中文字符转横线>--p2-<20 位十六进制>`。这个 `p2-` 后缀由 Trae 内部生成，
本地 SQLite 存储中不存在该映射，用已知样本反推 md5/sha1/sha256 等常见算法也复现不出来——
**因此该目录无法在本地伪造**，写错目录 Trae 不会读取。

所以本次迁移走的是"**工作区内的上下文文件 + 完整会话导出**"这条路线：
Trae（VS Code fork，支持 `chat.useAgentsMdFile`）打开本工作区时会自动读取根目录的
[AGENTS.md](../../AGENTS.md)，由它指向本目录。

## 维护约定

- 这些文件**不进构建产物**（不在 `src/`、`public/`、`out/` 路径上），也不需要任何构建步骤。
- 目录**默认随 git 提交**，便于协作者与换机后仍有上下文；若不希望进仓库，请显式加入 `.gitignore`。
- 会话记录是**历史留档，不要回改**。项目规则变化时更新 `PROJECT-CONTEXT.md`，
  并在文中注明核对日期。
